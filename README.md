# Fama-French 五因子模型在中国 A 股市场的适用性检验

> 课程研究整理版。仓库整理了最终版 Python 脚本和历史汇总输出，原始课程数据库不公开。当前结果文件尚未由仓库代码重新生成，方法与结果口径仍需进一步核验。

## 项目简介

项目考察 Fama-French 五因子框架对中国 A 股收益差异的解释情况。现有最终版脚本读取月度个股收益与市值、无风险利率、年度财务指标和月度五因子数据，按市值与账面市值比各分五组，构造 25 个组合，并生成组合收益、因子描述统计和因子相关系数表。

样本标题标注为 2006 年 1 月至 2024 年 12 月。组合按每年 12 月截面形成，并使用下一年度收益。因而可用于持有期分析的区间不等于因子数据标注区间。收益采用组合内股票等权月均值。

## 研究结果：历史输出，不是本仓库的复现结果

现有汇总表显示：

- 组合收益表覆盖 25 个市值与账面市值比分组，每个组合记录 214 个月观测。`Small_Low` 的月均超额收益率为 2.3075%，`Big_Low` 为 0.9161%。
- 五因子统计表覆盖 228 个月观测。表中市场因子均值为 0.009，SMB 均值为 0.009，HML 均值为 0.000，RMW 均值为 -0.002，CMA 均值为 0.001。
- 历史回归表包含 10 个代表性组合，调整 R² 在 0.878 至 0.956 之间。该回归表来自旧版结果工作簿，未能由当前最终版脚本生成。

上列数据直接摘自随项目整理的汇总表。统计口径和计算流程尚未由本仓库完整复跑，故不据此宣称模型具有稳定的定价能力，也不采纳原论文中无法与代码或汇总表对应的政策窗口、行业和策略收益数字。

- `scripts/build_archived_tables.py` 是对提供的最终版脚本做路径整理后的版本，保留其 5×5 组合构造，并生成组合收益、因子描述统计和因子相关系数表。
- 提供的“留痕版”包含多个不同的组合形成流程和重复分析段落，未作为可复现主脚本发布。

## 运行说明

需先通过授权渠道取得课程所需数据。将其整理成 `data/README.md` 所列目录结构后，在 PowerShell 中设置数据和输出目录：

```powershell
$env:SAS_DATA_ROOT = "D:\authorized\SAS-course-data"
$env:FF5_OUTPUT_DIR = ".\outputs"
python .\scripts\build_archived_tables.py
```

安装依赖：

```powershell
pip install -r requirements.txt
```

脚本目前生成前三张表。它不会生成 `portfolio_regressions.csv`，因为原始回归输出所依赖的代码版本尚未与结果表核对。
